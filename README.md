# Site Dia dos Namorados

Site estatico romantico para publicar no GitHub Pages.

## Personalizar

1. Abra `script.js`.
2. Troque `whatsAppParts.yours` e `whatsAppParts.partner` pelos numeros em partes.
   Exemplo para `5511999999999`: `["55", "11", "99999", "9999"]`.
3. Coloque suas fotos na pasta `assets/fotos` com os nomes:
   - `foto_1.jpg`
   - `foto_2.jpg`
   - `foto_3.jpg`
   - `foto_4.jpg`
   - `foto_5.jpg`
   - `foto_6.jpg`
   - `foto_7.jpg`
   - `foto_8.jpg`
   - `foto_9.jpeg`
   - `foto_10.jpeg`
4. Coloque a musica em `assets/audio/you-and-i.mp3`.
5. Edite a lista `poems` com seus poemas.

## Privacidade recomendada

Este site foi feito para GitHub Pages. Trate tudo como publico: codigo, fotos e links podem ser vistos por qualquer pessoa que tenha acesso ao site ou ao repositorio.

Para reduzir exposicao acidental:

1. O arquivo `robots.txt` e a meta tag `robots` pedem para buscadores nao indexarem o site.
2. Os WhatsApps ficam separados em partes no `script.js`, apenas para nao aparecerem como um numero obvio. Isso nao e criptografia real.
3. Use fotos exportadas em baixa/media resolucao, sem localizacao e sem metadados. Nao suba fotos originais da camera/celular.
4. Evite colocar nomes completos, endereco, documentos, placas, rotinas ou informacoes muito pessoais nas imagens e textos.

## Publicar no GitHub Pages

1. Crie um repositorio publico no GitHub.
2. Envie estes arquivos para o repositorio.
3. Va em `Settings` > `Pages`.
4. Em `Build and deployment`, selecione `Deploy from a branch`.
5. Escolha a branch `main` e a pasta `/root`.
6. Salve e aguarde o link do Pages aparecer.
